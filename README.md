# Kilo Test Repo

A collection of small projects and experiments for testing the Kilo AI IDE.

## Projects

| Project | Type | Description |
|---------|------|-------------|
| [atari-dino](./atari-dino/) | Atari 2600 Assembly | Chrome-style Dino runner port for the Atari 2600 using 6502 assembly and DASM. |
| [homepage](./homepage/) | HTML/CSS/JS | Single-page personal homepage. |
| [k8s-upgrade-modeling](./k8s-upgrade-modeling/) | TLA+ | Formal specification of Kubernetes/Helm application upgrades with concurrency constraints. |
| [k8s-wordle](./k8s-wordle/) | JavaScript/HTML/CSS | Endless Wordle clone for Kubernetes terms with stats, multiple modes, and no build step. |
| [motionguard](./motionguard/) | Android/Kotlin/Java | Motion-activated camera app with OpenCV detection and cloud storage integration (Google Drive, OneDrive, Dropbox, MEGA). |
| [pixel-runner](./pixel-runner/) | HTML5 Canvas/JavaScript | Pixel-art side-scrolling platformer designed for web and Android deployment via Cordova/Capacitor. |

## Getting Started

Each project is self-contained in its own directory. See the README in each project for specific setup, build, and run instructions.
