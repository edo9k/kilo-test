# LangPlayer download cronjob
# Run download_episodes.py twice a day (03:00 and 15:00 server time) to refresh
# the per-language episode bucket, prune audio and logs older than 4 days.
#
# Each run writes its own timestamped log to langplayer/logs/.
#
# Install with: crontab -e  (then paste the line below, adjusting the path)
#
# 0 3,15 * * * /usr/bin/python3 /absolute/path/to/langplayer/download_episodes.py
